# 家族で使える家計簿アプリ

## 1. 概要
このアプリは、家族それぞれの収支を個別に、または全体で管理できる家計簿アプリです。
SQLite3を使用してデータを保存しています。

## 2. 主な機能
- **家族登録**: 使う人の名前を登録できます。
- **収支管理**: 収入・支出のデータを追加、編集、削除できます。
- **表示切り替え（フィルタリング）**: 
  - 家族（作成者）ごと、または特定のカテゴリごとにデータを絞り込んで表示できます。
  - 「家族」と「カテゴリ」を組み合わせて、「パパの食費だけ」といった詳細な絞り込みも可能です。
- **自動計算**: 収入と支出に基づき、現在の残高を自動で計算します。

## 3. 使い方

1. 必要なパッケージをインストールします。
   ```bash
   pip install flask

2. データベースを初期化します（初回のみ、またはリセット時）。
Bash
python database.py

3. アプリを起動します。
Bash
python app.py

4. ブラウザで http://127.0.0.1:5000 にアクセスしてください。
