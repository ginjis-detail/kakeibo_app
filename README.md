# 家族で使える家計簿アプリ

## 1. 概要
このアプリは、家族それぞれの収支を個別に、または全体で管理できる家計簿アプリです。
SQLite3を使用してデータを保存しています。

## 2. 主な機能
- **家族登録**: 使う人の名前を登録できます。
- **収支管理**: 収入・支出のデータを追加、編集、削除できます。
- **表示切り替え**: 特定の家族だけのデータに絞り込んで表示できます。
- **自動計算**: 収入と支出に基づき、現在の残高を自動で計算します。
